# 🎌 Projeto Anime

Um projeto pessoal desenvolvido antes da graduação com foco em experiência visual, ambientação temática e interatividade utilizando HTML, CSS e JavaScript.

---

## 📌 Sobre o Projeto

O Projeto Anime foi criado com o objetivo de apresentar diferentes universos de animes de forma imersiva e dinâmica.

Cada tela representa um anime diferente, contendo:

* imagem temática em tela cheia
* descrição personalizada
* troca dinâmica de conteúdo
* música específica para cada anime
* navegação em formato de carrossel

O projeto foi desenvolvido de forma totalmente autodidata, antes do início da faculdade, servindo como um dos primeiros contatos com desenvolvimento web.

---

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

---

## ✨ Funcionalidades

* Carrossel interativo
* Alteração dinâmica de imagens
* Troca de informações conforme o anime selecionado
* Reprodução de música personalizada para cada tela
* Interface visual temática
* Layout responsivo
* Controle de navegação por botões
